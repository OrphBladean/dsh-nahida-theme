## 中等文案（V2EX / 微信群 / Telegram / Discord）

标题：给 DSH 写了个纳西妲主题插件（草元素 / 四叶草 / 祝福语 / 壁纸）

正文：

最近在用 DeepSeek Harness（DSH）的 Web GUI，顺手写了一个纳西妲主题的皮肤插件。它不是单纯换色：

- 用主题令牌覆盖层改主色、画布和侧边栏，浅色/深色都能用，不改宿主主题设置；
- 原创四叶草徽记替换侧边栏品牌位，也出现在新会话欢迎页；
- 输入框下方有一条轮播祝福语，跟随界面语言切换中/英/日；
- 15 张聊天区壁纸，可在「设置 → 纳西妲主题」或右下角四叶草按钮里选，带柔化遮罩；
- 视图边缘有几片缓慢飘落的草叶，开启“减少动态效果”会自动静止。

安装一行：
`dsh plugin --profile web add dsh-nahida-theme`

GitHub（含安装说明、测试、README）：https://github.com/OrphBladean/dsh-nahida-theme
npm：https://www.npmjs.com/package/dsh-nahida-theme

MIT，代码、文案和插画都是在 DSH 里做的；非官方同人项目，没有使用游戏素材。

## 发布小贴士

1. **配截图比文字有效**：发之前先截 1–2 张（浅色 + 深色，能看到徽记和祝福语）。
2. 发到有 DSH 用户的群 / 社区，比发在无人看的动态更有效。
3. 同一个链接可以在 GitHub 话题页里被搜到：仓库已经带 `dsh-plugin` topic，DSH 插件市场会收录。
4. 不要在短时间内重复刷屏；真实的使用反馈比 star 更有价值。
5. 壁纸层需要宿主提供 `conversation.hero.frame` 插槽；在暂未提供该插槽的 DSH 版本（如 0.2.2-rc.1）上，设置页能打开但壁纸不显示，发布时可按自己的版本说明。
